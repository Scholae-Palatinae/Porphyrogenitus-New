# Porphyrogenitus_A_Byzantine_Text_RPG_Experience
<img width="342" height="241" alt="scholae palatinae" src="https://github.com/user-attachments/assets/9b2d3ea4-3c94-4d51-958a-88d36dcea5c4" />

"Porphyrogenitus" is a text RPG game set in the medieval Byzantine Empire at its zenith, during Basil II's reign ( 10th and 11th century AD, Byzantine-Bulgarian wars 913 AD, invasion of the Rus' Vikings 941 AD, the reconquests of Crete and eastern provinces by Basileus Nikephoros Phokas and Ioannes Tzimiskes & Rise of Basil the II and the Macedonian Renaissance). It puts the player deep into the Greco-Roman society, politics and way of living. As the sole responsible for managing and exploiting various resources, from military to economic and social, you get to do some serious decision-making and fulfil actions that can change the course of history.

In this project, our team, Scholae Palatinae, tries to create an authentic, medieval Roman
TRPG experience, combining history of the peak of the Byzantine Empire (reign of Basil II)
and RPG elements (such as in Mount and Blade: Warband, Crusader Kings II & III).

A very special thanks for the art contribution to the ByzantineTales Team from Greece (Chrysa Sakellariou).

Update section:

Built-in Logger System:
1) The logger is a convenient way to be able to write error code and be able to distinguish between debug info and error messages.
2) You can also save the logs and have them written to a text file so you can monitor them later.

Console Class:
1) Allows you to create a buffer for holding text
2) Draw that text to a specific location in the console
3) Color the text based on the 16 colors available for the windows console.
